# The Devil You Owe

Duff's top-down 3D action RPG for Android phones: a half-demon who hunts demons. Godot 4.7.2,
GDScript, portrait 720x1280, Compatibility renderer.

Built on duffpowell-commits/godot-game-starter (Milestone 0, Nov 21, 2026): CI + signed APK,
in-app updates, bug reports, full scene flow, autosave, settings and accessibility, dev menu,
autoplay bot. Latest build: Releases -> `dev` -> `hunter.apk`.

Start with AGENTS.md (rules and commands), then CLAUDE.md (where things stand) and
docs/BUILD_SPEC.md (what to build).
Why this README changed (Nov 21): the copy brought the starter's README, which described the template.
